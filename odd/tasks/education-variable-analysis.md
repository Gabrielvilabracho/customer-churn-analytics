## Specs
- S1: "generar el analisis interactivo de las variables" — provide a real-artifact-backed education page with variable, cohort and sample controls; preserve the legacy dashboard.
- S2: "Coeficientes interpretados de la regresión logística." and "Dirección positiva o negativa de su efecto." — expose fitted coefficients, units, odds ratios and categorical contrasts with non-causal explanations; never refit preprocessing.
- S3: "Importancia de cada variable." — held-out permutation importance and grouped mean absolute independent linear SHAP, explicitly distinguished from coefficients.
- S4: "Correlaciones con el burnout." — numeric point-biserial/Spearman and categorical Cramér's V, train/test comparisons, explicit target High versus Low/Medium, undefined values represented honestly.
- S5: "Explicaciones SHAP." — exact independent linear SHAP in log-odds using training background, grouped signed contributions, held-out global distributions and anonymized local explanations; verify additivity and probability parity.
- S6: "Comparaciones por cohortes de estudiantes." — counts, observed high-burnout rates, predicted risks, confidence intervals and held-out precision/recall; minimum-size suppression; academic and AI-use cohorts.
- S7: "aplicalo" — implement the proposed reproducible analysis → artifacts → API → interactive dashboard path and checks. Preserve existing published runs, CLI/output/HTTP contracts and the pre-existing `apps/web/next-env.d.ts` edit. No dataset download or redistribution.
