# AI Student Impact Data Dictionary

This is the canonical field-level contract for the 16-column CSV bound to Kaggle `laveshjadon/ai-impact-on-students`, version 1. It documents the bytes used by `education-v1`; it does not validate the synthetic measurements as real-student evidence.

## Evidence and reading rules

- **Publisher description** means the version-1 Kaggle public API description checked on 2026-11-13. The local CSV is byte-identical to that version.
- **Observed** means a value or category represented in verified local aggregate artifacts or the verified source record. A publisher-reported range is descriptive evidence, not an enforced schema constraint.
- All CSV fields are read lexically from CSV. “Analysis type” records how the education model treats a field after parsing.
- Exact generator code, random seed, survey/instrument wording, collection timing, and burnout-label construction are unavailable. Field names do not prove temporal order.
- Every field is synthetic. None is a validated clinical, psychological, educational, or causal measure.

## Cross-field handling

The `education-v1` model includes the 12 predictors in rows 2–13. Numeric predictors are transformed as numeric values; string predictors are treated categorically. `Student_ID` is retained only for split/identity integrity and excluded from the model. `Post_Semester_GPA` and `Skill_Retention_Score` are excluded as post-outcome leakage fields for the burnout task. `Burnout_Risk_Level` is the target and is binarized as High versus Low + Medium.

The current file has no empty CSV cells, no duplicate full rows, and 50,000 unique IDs. Those checks do not prove that values are semantically valid, that categories are complete, or that sentinel values are absent. The pipeline's observed feature types and exclusions are authoritative for this experiment; publisher ranges are not automatic runtime validators.

## Measurement and reuse limits

- The dataset is synthetic portfolio evidence. Do not present any field as a measured real-student attribute or any target as validated student risk.
- Temporal ordering is supported only where the publisher explicitly says pre-semester or post-semester. The timing of the burnout label and the remaining predictors is not established, so longitudinal or forecasting claims are unsupported.
- Category labels and numeric scales may encode unknown generator assumptions. Associations can therefore reflect generation rules rather than educational phenomena.
- No demographic/protected attributes, institution identifiers, geography, sampling frame, missingness mechanism, or instrument-validation evidence is available. Their absence prevents representativeness and fairness claims; it does not establish fairness.
- Do not infer causal effects, clinical meaning, intervention benefit, or safe operational thresholds from these fields.
